Attention is a soft lookup

A dict returns a value only when the key matches exactly. Attention scores every key against the query and blends all the values, so drag q anywhere and it still answers.

Crosstalk

Two pairs share one matrix, so reading with k1 returns v1 plus (k1·k2) times v2. Tilt k2 toward k1 and watch v2 leak in.

S = k1v1T + k2v2T

STk1 = v1(k1·k1) + v2(k1·k2)

= v1 + 0.00 v2

Write the difference

k already holds v1, and each press of Write stores v2 at k in both memories. The plain sum piles every write on top, while the delta rule closes a fraction β of the gap each time.

plain sum: S ← S + k vT

delta rule: S ← S + β k (v − STk)T

Read in the post: The Delta Rule: Read What's Stored, Write the Difference

300 overwrites

300 random updates to 8 keys, scored on how far each key's read is from its latest value. The plain sum climbs to 6.19 and the delta rule at β = 1 holds at 0.19, the crosstalk between keys. At β = 0.5 it ends at 0.59, since each write leaves half of the old value behind.
